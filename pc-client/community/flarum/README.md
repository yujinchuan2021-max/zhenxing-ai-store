# 枕星AI助手 Flarum 预发布环境

该目录固定使用 Flarum `2.0.0-rc.5`。Flarum 2.0 尚处于 RC 阶段，因此这里只作为预发布验证环境，不代表已经完成生产验收。

## 启动

1. 将 `.env.example` 复制为 `.env`。
2. 替换两个数据库密码，不能保留示例值。
3. 运行：

```powershell
docker compose --env-file .env up --build -d
```

4. 打开 `http://127.0.0.1:8088`，使用网页安装向导：

- 数据库驱动：MySQL
- 数据库主机：`database`
- 数据库名称、用户和密码：使用 `.env` 中对应值
- 管理员账号和密码：由用户在安装页面自行设置

客户端不会保存数据库密码或论坛管理员密码。

## 上线前门槛

- 等待并评估 Flarum 2.0 稳定版，升级前备份数据库和上传文件。
- 改用真实域名和 HTTPS 反向代理。
- 将 `FORUM_BIND_ADDRESS` 保持为 `127.0.0.1`，除非已有受控防火墙和反向代理。
- 配置邮件服务后再开放注册和密码找回。
- 完成备份恢复、升级、权限、垃圾内容治理和真实用户注册验收。
