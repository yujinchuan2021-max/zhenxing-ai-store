# 第四阶段：后台管理与安全发布

## 已完成

- 厂商：新增、编辑、删除、显示顺序、启停、文字图标、HTTPS 图片图标、颜色、描述、官网和教程；同一厂商资料由两个目录视图复用。
- 产品：新增、编辑、删除、归属厂商、显示顺序、启停、类别、单值 `directoryKind`、官网、教程、有序入口、通用模块和经过客户端批准的安装配置。
- 生态资源：新增、编辑、删除、排序、启停、`skill/mcp/plugin` 类型、来源产品和目标关系；同一资源只保存一份。
- 资源目标：选择目标产品、兼容性、客户端固定模块、审核配置和有限能力；资源商店按类型、目标厂商和目标产品自动投影。
- 首页：品牌、轮播新增/删除/排序、精选厂商。
- 客户端版本：版本、安装包地址、SHA-256、文件大小、更新说明、灰度和启停。
- 下载源：官方源优先，官方不可用后才使用启用的国内镜像；支持同级顺序和探测超时。
- 发布：独立发布前校验、Ed25519 签名、不可变目录历史和“回滚为更高版本”。

## 安全边界

- 后台没有 EXE、Shell、PowerShell、CMD、命令参数或脚本字段。
- 后台不能输入资源包名、任意 URL、任意配置片段或本地路径；资源目标只能引用客户端公开的固定模块与审核配置。
- 环境下载源只保存客户端已批准的 `environmentId`、`sourceId`、`enabled` 和 `order`。
- 下载 URL、域名、文件名与允许跳转域名全部保留在客户端本地白名单。
- 官方源不能从后台停用，也不能被镜像排到前面。
- 已审核桌面软件、CLI 和本地模型产品仍按产品 ID、厂商归属、类型、依赖和精确安装包执行本地白名单校验。
- 下载源偏好进入签名目录，因此与目录版本一起保留历史并参与回滚。
