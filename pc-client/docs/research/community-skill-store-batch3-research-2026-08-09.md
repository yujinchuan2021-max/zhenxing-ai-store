# Community Skill Store Batch 3 research

Candidate-only. Four new primary repositories were reviewed at pinned commits: [swyxio/skills](https://github.com/swyxio/skills), [CopilotKit/CopilotKit](https://github.com/CopilotKit/CopilotKit/tree/main/skills), [DenisSergeevitch/agents-best-practices](https://github.com/DenisSergeevitch/agents-best-practices), and [Databricks Agent Skills](https://github.com/databricks/databricks-agent-skills).

B3 adds 40 exact canonical Skill directories and 103 website-only link targets. It contains no installation profile, no managed action, no Agent binding, and no Workflow dependency. B1+B2+B3 therefore stages 104 reviewed-community Skills and 777 total resource targets in a preview, exceeding the 100-Skill target without touching active state.

Databricks upstream documents account, CLI, marketplace, and hook flows; those are deliberately not projected. Its B3 records are guarded source links only. All candidate records retain fixed revisions, direct author/organization source, license evidence, raw-to-canonical tag evidence, and a separate review/risk decision.
