# AI 产品目录持续扩充核验

## 范围与结论

本轮从正式目录的 **209 个厂商、363 个产品、118 项生态资源**继续扩充，不再按“第几批”切断工作。核验范围覆盖照片与视频、科研与知识管理、项目协作、会议、数据分析、开发运维、远程支持和 Adobe 创作套件。

正式录入 **29 个新厂商和 45 个产品**，新基线为 **238 个厂商、408 个产品、118 项生态资源**。其中 42 个是 Windows 图形产品，3 个是 Web 产品；没有扩充 CLI，没有把同一可视产品的 Web 与 Windows 入口拆成重复产品。

本轮资料只采用厂商官网、官方帮助中心、官方产品文档或官方发布说明。目录中的 Windows 产品继续调用固定 `desktop-official` 模块：客户端只让系统浏览器打开厂商维护的官方页面，不下载、解析、校验或启动图形安装器，也不在用户浏览目录时探测环境。Coda AI、Reclaim.ai 和 Adobe Firefly 调用固定 `web-link` 模块。

## 后台和客户端边界

- 45 个产品都由后台目录记录名称、描述、分类、官网、教程和入口；前端不写产品特例。
- 42 个 Windows 图形产品使用同一个固定 `desktop-official` 模块，后台不能传 EXE、MSI、Shell、PowerShell、CMD、哈希或任意执行参数。
- 3 个 Web 产品使用同一个固定 `web-link` 模块。
- Web 与 Windows 属于同一产品时只计算一次；CLI 仍应单独说明“命令行工具”，本轮没有扩充 CLI。
- 新厂商未取得可明确用于第三方目录的方形品牌素材前，统一进入审核文字兜底清单；禁止拿 favicon、搜索图片、GitHub 个人头像或相似厂商 Logo 冒充。
- 扩充脚本可重复执行，厂商、产品和图标兜底清单均不会重复写入。

## 本轮没有做的事

- 没有把普通桌面图形软件升级为 AI Hub 受管安装；产品只有完成逐版本下载、签名、检测、启动、更新和卸载审计后才可能进入受管白名单。
- 没有因为页面包含 API、MCP、Plugin 或 Skill 就自动新增资源；生态资源需要独立核验官方来源、宿主关系和安全边界。
- 没有仅为增加数量而录入无官方 AI 证据、已停止维护、仅 macOS、仅移动端或第三方插件产品。
