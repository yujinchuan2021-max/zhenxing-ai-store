# Public Skill / Agent-skill hubs census (2026-08-14)

## Result

This second-pass census evaluated **62 classified source groups** across **91 unique URLs and 47 hostnames**: **A 12 / B 21 / C 20 / D 9**. A row can group multiple related or contrasting objects, so the row count is not a count of distinct domains, repositories or Skills. A means a first-party or unusually strong, traceable discovery source; B means a useful independent lead index; C means adjacent capability, a single-publisher collection, self-hostable software, or a materially weaker catalog; D means deprecated, empty/pre-launch, internally inconsistent, unreachable, or unsuitable as an AI Hub discovery input.

The central finding is that compatibility is not a registry. Agent Skills (`SKILL.md`), host plugins, MCP servers, rules, prompts, recipes and agents are frequently marketed together, but AI Hub must preserve their resource types. No count below is silently treated as unique Skills, safety evidence, authorship, license, or compatibility proof.

## Method and boundaries

- Observed **2026-08-14 (Asia/Shanghai)**. Search engines supplied leads only; decisions use the linked live site, official documentation, public repository/tree/manifest, `robots.txt`, or a small sitemap probe.
- No `/api`, `/_next`, login, install, archive/package download, script execution, rate-limit bypass or bulk crawl was used. A site's documented API is mentioned as an enumeration contract but was not called.
- `R:` below records the public robots signal observed. “allow” is not a license. `L:` records the license/login boundary; an index license never relicenses upstream content.
- Scale is an exact visible manifest/tree count where stated, otherwise explicitly a **site claim**. Mutable counters are timestamped by this observation.
- Canonical candidate identity is `source host + owner/repository + Skill path + pinned commit`, never aggregator slug, rank, stars or installs.

## Duplicate, provenance and policy conclusions

1. **The same upstream is multiplied by dozens of storefronts.** Anthropic, OpenAI, Microsoft, Vercel, `obra/superpowers` and popular publisher repos recur in Skills.sh, SkillsMP, SkillMD, SkillScope, MCP.Directory, MCP Market, Claude SEO directories and awesome lists. Store one canonical pinned path and attach discovery observations; never create one resource per storefront.
2. **“Official” has three meanings.** First-party publisher repository is strong; an official host's third-party marketplace is curated but not authored; an independent site's “Official” badge is only a claim. Only the first closes authorship by itself.
3. **Mixed packages require file-level routing.** ClawHub, OpenAI/Claude/Cursor/Gemini plugin catalogs, GitHub Awesome Copilot, Continue, Goose, LobeHub and MCP directories mix Skills with plugins, MCP, agents, prompts, rules, recipes, commands and hooks.
4. **Counts are not comparable.** They may represent files, folders, repository collections, versions, telemetry, generated entries, duplicates or mixed resources. The most striking warning is SkillsMP's 2.6M file claim versus finite official repositories and ClaudSkills' two conflicting counters on one page.
5. **License follows content.** Registry/software/list MIT or Apache status never licenses linked or mirrored Skill bodies. Missing, conflicting or noncommercial/source-available terms mean link-only/deferred.
6. **Robots and ToS are collection boundaries, not permission to republish.** Honor every disallow, page/login boundary and rate limit; an allowed public page still supplies only evidence, not redistribution rights.

4. Treat Hermes as a federation map: enumerate its 79 bundled and 113 optional official catalog entries separately; do not ingest federated Skills.sh/ClawHub/LobeHub/browse.sh results again.
