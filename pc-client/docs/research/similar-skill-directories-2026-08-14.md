# Similar public Skill / Agent-skill directories (2026-08-14)

## Decision

Eight currently reachable public directories or repository indexes are worth retaining as discovery inputs. Four are **A** sources: Skills.sh, ClawHub, OpenAI's current Plugins marketplace repository, and Anthropic's Skills repository. Four are **B** leads: Skills Playground, TheSkillMD, VoltAgent's general Agent Skills list, and VoltAgent's OpenClaw mirror. Skills Directory and Codex Skills Registry are **C** because their redistribution/provenance or single-maintainer-copy risks are materially higher.

No aggregator result is publication, installation, execution, publisher, license, security, or CompatibleHost evidence. A discovered item remains deferred until an original-author repository is found, a fixed revision is pinned, the exact `SKILL.md` and same-revision license are verified, and runtime/permission behavior is reviewed.

## Research boundary and method

- Observation date: **2026-08-14 (Asia/Shanghai)**. Public HTML, public repository pages/manifests, `robots.txt`, and a small number of sitemap probes were used.
- No `/api`, `/_next`, login/auth surface, package/ZIP, CLI install, script, private endpoint, rate-limit bypass, bulk crawl, catalog/state write, save, sign, release, or publish action was used.
- Public counts below are either an exact visible manifest/sitemap count or the site's own visible claim. They are not silently converted into verified unique-skill counts.
- `robots.txt` is a crawl signal, not a content license. A repository's license covers that repository unless it expressly covers linked third-party Skill bodies.
- The Agent Skills specification site (`https://agentskills.io/`) is authoritative format documentation, not a directory, and is therefore not ranked below.

## Cross-source duplicate and trust risks

1. **Same upstream, many storefronts:** Anthropic, OpenAI, Vercel, Supabase and other popular repositories recur across Skills.sh, Skills Playground, TheSkillMD, Skills Directory, Codex Skills Registry and both VoltAgent lists. Canonical identity must be `source host + owner/repository + exact Skill path + pinned commit`, not aggregator slug/name.
2. **Copies and forks:** a GitHub backlink can lead to a fork, generated catalog, or repackaged Skill rather than the original author. Check repository ownership/history and locate the earliest authoritative source; do not use stars or install counts as provenance.
3. **Mixed resource types:** OpenAI Plugins, ClawHub and broad community indexes mix Skills with plugins, MCP, agents, commands, prompts or rules. Route by actual files/manifest, never by marketing label.
4. **Mutable rankings and scans:** downloads, stars, `Official`, `Verified`, grades and automated scans can change and do not establish safety, license, platform support or authorship.
5. **License layering:** an index/repository license does not automatically license linked third-party Skill bodies. Verify the Skill folder/repository license at the same pinned commit; absent or conflicting license means link-only/deferred.

## Minimum safe next enumeration

1. Start with the **two finite official manifests**: Anthropic's 17 visible Skill folders and only the Skill-bearing folders referenced by OpenAI's 180-entry mixed plugin manifest. Record repository, path and current 40-character commit; do not install.
2. Sample at most **10 public Skills.sh sitemap detail URLs** not already represented by official manifests. Store only aggregator URL, upstream repository/path, visible publisher label as untrusted text, and observation time.
3. Sample at most **10 public ClawHub Skill pages**, excluding plugins. Because source-repository provenance is not guaranteed, accept none unless a separately reachable original-author repository closes exact path, revision and license.
4. Use B sources only to fill missing upstream repository candidates. Do not enumerate their full sitemaps. If the same canonical path appears in multiple directories, retain one resource identity and list the extra sites as discovery observations.
5. Before any catalog candidate, manually inspect the exact pinned `SKILL.md`, bundled scripts/assets, declared binaries/env/network/filesystem/write operations, same-revision license, and compatible host evidence. Proposed exposure remains guarded `resource-link`/website until an independent runtime and permission review authorizes more.
