# ADR-0003：产品与扩展资源分层

状态：已采用

AI Hub 将桌面、CLI、Web 和 Agent 工具统一建模为厂商旗下的产品，并按桌面端、CLI、Web 的顺序选择首选入口。Skill 与 MCP 服务建模为宿主产品下的扩展资源，不进入首页或厂商的一级产品统计；这样既能保持“厂商 → 产品”的主信息架构，又能在产品内部持续扩充生态。

扩展资源的一键安装由两个独立审核身份共同决定：扩展安装配置固定资源来源与内容身份，目标适配器固定宿主产品的配置格式、目录和写入规则。后台只允许增删查改展示资料，并选择客户端公开的扩展安装配置和目标适配器；后台不能下发命令、脚本、任意包名、任意配置片段或任意文件路径。

## 后果

- Agent 是产品类别，不新增厂商专属安装流程；其桌面版、CLI 或 Web 入口继续调用现有产品模块。
- 产品可以拥有排序、启停的扩展资源子目录，扩展资源可以在产品之间移动。
- 同一个 MCP 服务可以支持多个宿主产品，但每个“扩展资源 × 安装目标”组合都必须由客户端本地白名单批准。
- 安装和卸载必须保存所有权收据，只能删除 AI Hub 自己写入的文件或配置项，不能覆盖或清理用户手工配置。
