# ADR-0004：可视化产品聚合入口，CLI 独立展示

状态：已采用；扩展资源展示关系由 [ADR-0006](0006-catalog-views-and-ecosystem-resource-stores.md) 更新

> 历史说明：本文件关于可视化产品聚合入口和 CLI 独立展示的决定继续有效；最后一项“Skill 与 MCP 使用产品子目录”的后果已被 ADR-0006 取代。

同一可视化产品的官网、Web 版和 Windows 客户端不再分别建立产品记录，而是作为一个产品卡片内的有序 `entryPoints`。产品统计以产品身份为准，不以入口数量为准。CLI 面向终端用户，交互预期与图形产品不同，因此始终保留为厂商下的一级独立产品，不能放进其他产品的组件目录。

入口只描述展示和路由：`website`、`web`、`tutorial`、`external` 保存 HTTPS 链接；`desktop`、`cli` 不保存链接、命令、参数或路径，只调用产品现有的 `moduleId + installProfileId`。数组顺序就是客户端按钮顺序。缺少 `entryPoints` 的旧目录由客户端生成兼容入口，因此可以先升级客户端，再发布新目录。

## 后果

- 后台可以增删和排序产品入口，客户端不再为具体厂商编写按钮。
- 普通链接调整无需升级客户端；本地安装、检测、打开和卸载能力仍受客户端固定模块与审核配置约束。
- 新的本地执行原语仍需要升级客户端，但厂商的链接、文案和现有模块参数变化不需要修改前端页面。
- ChatGPT、Claude、豆包、Microsoft Copilot、千问和腾讯元宝各合并一组 Web/Windows 重复记录，并保留原托管桌面产品 ID，从而不迁移白名单、收据或本地状态。
- Skill 与 MCP 继续使用 ADR-0003 的宿主产品子目录，不进入一级产品列表。
