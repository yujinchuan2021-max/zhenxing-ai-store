# ADR-0008：封包客户端固定身份与社区服务地址

状态：已采用

## 决策

封包后的 Windows 客户端只从封包内受发布门禁校验的 `clientServices` 元数据读取身份服务和社区 origin，不读取运行时环境变量。正式包只接受非回环 HTTPS origin；本地验收包只接受固定回环 origin。目录、更新、身份与社区配置必须同时通过同一 `beforePack` 门禁，任一缺失都会停止封包。未封包开发模式可以通过环境变量连接开发服务。

## 后果

- 正式客户端不会因为用户机器的环境变量而把登录凭据或会话发送到其他地址；
- 正式身份与社区 HTTPS 地址尚未配置时，生产封包保持关闭，而普通前端构建不受影响；
- 本地验收包继续连接本机 Docker，且其配置不会混入生产包；
- 身份登录、社区跳转和内嵌社区导航始终使用同一份服务配置，不再各自回退到不同的 localhost。
