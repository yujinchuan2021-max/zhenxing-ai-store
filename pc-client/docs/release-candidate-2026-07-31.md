# AI Hub PC 本地发布候选报告

日期：2026-07-31

## 结论

AI Hub PC 已具备本地发布候选基线。代码、目录、账号社区、Windows 打包、覆盖升级、本地 HTTPS 发布和回滚链均通过自动化验证。

这不是生产发布批准，也不代表第三方产品已经完成用户实机安装验收。

## 客户端与安装器

- 正式配置版 Portable 和 NSIS Setup 构建成功。
- 本地 HTTPS 验收版 Portable 和 NSIS Setup 构建成功。
- Node 25 不再通过 `spawnSync` 直接启动 `.cmd`。
- Electron 解包统一在系统临时目录完成，避免项目目录句柄锁定。
- `0.1.0 → 0.1.1` 覆盖升级成功。
- 升级前用户数据标记在升级后保持不变。
- 基础版和升级版均能启动并保持后台托盘进程。
- 最终卸载后安装目录、注册表项、快捷方式和测试标记均清理完成。

## 目录与发布服务

- 后台活动目录：v9。
- Docker HTTPS 发布目录：v9。
- 更新版本：`0.1.1`。
- HTTPS 根证书校验、签名目录、签名更新清单、Range 下载、文件大小和 SHA-256 均通过。
- 已验证从 v5 回滚到 v4，再恢复到 v5。

## 账号与社区

- 邮箱验证码注册、登录和持久会话通过。
- Flarum 用户自动映射通过。

## 安全门槛

- 241 项单元测试全部通过。
- 正式目录和更新 channel 保持禁用。
- 未提供正式域名、版本、安装包和环境密钥时，生产发布命令拒绝执行。
- 本地签名私钥、发布运行时和生成安装包不进入 Git。
- 后台仍不能下发任意本机命令；执行能力只来自客户端固定模块。
