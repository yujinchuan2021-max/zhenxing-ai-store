# AI Hub PC 本地发布候选报告

日期：2026-07-31

## 结论

AI Hub PC 已具备本地发布候选基线。代码、目录、账号社区、Windows 打包、覆盖升级、本地 HTTPS 发布和回滚链均通过自动化验证。

这不是生产发布批准，也不代表第三方产品已经完成用户实机安装验收。

## 客户端与安装器

- 正式配置版 Portable 和 NSIS Setup 构建成功。
- 本地 HTTPS 验收版 Portable 和 NSIS Setup 构建成功。
- Node 25 不再通过 `spawnSync` 直接启动 `.cmd`。
- Electron 解包统一在系统临时目录完成，避免项目目录句柄锁定。
- `0.1.0 → 0.1.1` 覆盖升级成功。
- 升级前用户数据标记在升级后保持不变。
- 基础版和升级版均能启动并保持后台托盘进程。
- 最终卸载后安装目录、注册表项、快捷方式和测试标记均清理完成。
- 正式配置版与本地 HTTPS 验收版已在桌面分发策略更新后重新构建。

## 首批已审核桌面产品

- ChatGPT Desktop 使用当前主应用 Store ID `9PLM9XGG6VKS` 的 Microsoft Store 官方安装引导器，界面不再把引导器描述为完整应用安装包。
- Claude Desktop 普通用户使用官方 x64 EXE；Team/Enterprise MSIX 不进入消费者目录。
- ComfyUI Desktop 已按当前官方名称迁移为 Comfy Desktop，保留旧名称探针兼容，不删除实例、共享模型和设置。
- Ollama 使用官方 `OllamaSetup.exe`，只运行可信注册卸载项，模型删除仍由用户明确选择。
- 四个产品继续复用统一桌面模块；后台只能选择客户端本地批准的产品配置，不能下发任意执行命令。

## 目录与发布服务

- 后台活动目录：v10。
- Docker HTTPS 发布目录：v10。
- 更新版本：`0.1.1`。
- HTTPS 根证书校验、签名目录、签名更新清单、Range 下载、文件大小和 SHA-256 均通过。
- 已验证从 v5 回滚到 v4，再恢复到 v5。
- 完成回滚验证后，使用原子本地升级流程发布 v10。
- 打包客户端实际读取远程目录 v10，并识别 `0.1.1` 更新。
- v9 在切换前完成签名与文件完整性备份，但因旧桌面分发策略不再兼容，恢复操作会继续被新策略拒绝。

## 账号与社区

- 邮箱验证码注册、登录和持久会话通过。
- Flarum 用户自动映射通过。
- 发帖、回复和社区浏览器跳转通过。
- 社区票据只能使用一次，重放被拒绝。
- Electron 渲染层只能通过受限 preload 接口访问身份功能。

## 官方 CLI 包隔离验收

- Codex CLI：`@openai/codex@0.146.0`，版本探针返回 `codex-cli 0.146.0`。
- Gemini CLI：`@google/gemini-cli@0.53.0`，版本探针返回 `0.53.0`。
- 两者均使用客户端固定动作和 `https://registry.npmjs.org/`。
- 安装与卸载阶段均禁用软件包生命周期脚本。
- 没有客户端收据时只能识别安装，不能生成卸载动作。
- 生成收据后只卸载对应官方包，旁路 sentinel 文件保持不变。
- 所有安装均位于系统临时目录，验收结束后清理，不修改全局 npm prefix。

## 安全门槛

- 244 项单元测试全部通过。
- 正式目录和更新 channel 保持禁用。
- 未提供正式域名、版本、安装包和环境密钥时，生产发布命令拒绝执行。
- 本地签名私钥、发布运行时和生成安装包不进入 Git。
- 后台仍不能下发任意本机命令；执行能力只来自客户端固定模块。
