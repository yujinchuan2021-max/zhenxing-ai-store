# 第五阶段完成范围

第五阶段目标是在暂时没有真实服务器时，建立可迁移的 Docker 发布环境，而不是模拟一个不受约束的线上执行后台。

已完成：

- 后台管理服务容器化，数据通过宿主机目录持久化。
- Caddy 只读 HTTPS 发布服务，只开放健康检查、签名清单、发布清单和批准的安装包路径。
- 两个服务只绑定本机回环地址，启用只读根文件系统、能力裁剪、进程上限、日志轮转和健康检查。
- 目录与更新使用不同的 Ed25519 密钥，私钥不进入容器、发布目录或客户端。
- 发布前完整校验、原子切换、自动备份、手工备份、历史列表和安全恢复。
- 目录版本 4、更新版本 0.1.1 的本地 HTTPS 发布链。
- PC 客户端从签名清单下载更新，固定完整 origin，校验文件大小和 SHA-256 后启动安装器。
- 生产 channel 与本地验收 channel 隔离。

仍属于真实上线阶段的事项：

- 公网域名和正式 CA 证书。
- Windows Authenticode 代码签名证书。
- 真实服务器部署、监控、告警和灾备。
- 用户机器上的最终点击安装验收。
