# 打开安装器后的自动安装检测

## 问题

客户端打开厂商安装器后，只显示“Windows 已接收打开请求”，需要用户完成安装后手动点击重新检测。打开安装器并不等于安装成功，但完全依赖手动检测也容易让流程停住。

## 实现

- 安装包在打开前仍会重新验证 SHA-256、Authenticode 和预期签发者。
- Windows 成功接收安装器打开请求后，产品进入“正在自动检测安装结果”。
- 客户端每 5 秒扫描一次可信安装证据，最多 120 次，约 10 分钟。
- 扫描沿用现有注册表、Appx、开始菜单和可信安装位置检测，不根据按钮点击推断成功。
- 检测到产品后自动切换为“已安装”，显示版本，并提供“打开软件”和“打开安装位置”。
- PowerShell 或注册表临时扫描失败不会立刻终止监控。
- 超时后保持未确认状态并保留“立即检测”，不会误报安装成功。
- 同一产品启动新的监控会取消旧监控；手动检测成功、组件卸载或应用退出也会取消监控，避免陈旧结果覆盖新状态。

## 验证边界

- 自动测试覆盖第三次扫描成功、临时扫描错误后恢复、超时不误报、取消后不再扫描。
- TypeScript 构建验证了监控器与真实 Electron IPC 的接线。
- AI Hub 自身 Windows 安装、启动、卸载生命周期继续实际执行。
- 本轮没有擅自运行 Comfy 或 Ollama 的安装向导，因此厂商安装器完成后的本机实际注册信息仍需用户测试新版客户端时验收。
