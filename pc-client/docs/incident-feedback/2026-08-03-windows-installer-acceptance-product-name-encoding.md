# Windows 安装包验收脚本误读中文产品名

日期：2026-08-03

## 现象与证据

`0.1.30` Local Setup 静默安装返回成功，但隔离验收脚本报告找不到主程序。安装目录实际存在 `枕星 AI.exe`，错误文本却显示乱码文件名。

## 根因

Windows PowerShell 5.1 按系统代码页读取无 BOM 的 UTF-8 脚本，脚本中硬编码的中文产品名被误解码。安装包本身、安装目录和主程序名称没有错误。

## 修复

- 验收脚本不再硬编码品牌中文名，统一从 `package.json` 的 `build.productName` 读取。
- 主程序、进程、快捷方式和卸载注册项匹配共用同一个产品名。
- 首次失败留下的隔离安装实例通过其正式卸载器清理，没有直接删除用户目录或注册表。

## 验证

重新运行同一个 `0.1.30` Setup 后，安装、启动、关闭到托盘、进程退出、静默卸载、注册项清理、隔离用户数据清理和快捷方式恢复全部通过。

## 防复发门禁

安装包验收脚本必须从构建元数据读取产品名和版本；品牌改名或 PowerShell 文件编码不能再次产生独立硬编码。
