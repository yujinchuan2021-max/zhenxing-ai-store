# 产品操作按钮被挤到下一行

## 现象

产品能力模块加入独立的“教程”入口后，Claude Desktop 产品卡片中的“工具官网”
和“打开教程”位于第一行，“一键安装”被挤到下一行中央。

## 证据

Electron 布局回归脚本在 1123 像素产品卡片宽度下测得三个按钮的垂直中心差为
75 像素。Windows 实际窗口截图与该测量一致。

## 根因

产品卡片仍使用旧的三列 Grid：产品信息、单个官网按钮、安装流程。新增教程按钮
成为第四个直接网格子项，CSS 自动把安装流程放进下一行。

## 被推翻的假设

按钮会因为安装流程使用 Flex 布局而自动保持在同一操作栏。Flex 只作用于安装流程
内部，不能管理它的两个兄弟按钮。

## 修复

- 增加统一的 `productActions` 操作栏。
- 官网、教程以及安装/打开/卸载流程全部进入该操作栏。
- 产品卡片只保留“产品信息 + 操作栏”两列。
- 窄窗口下操作栏整体移动到产品信息下方并左对齐。

## 验证

`npm.cmd run test:product-layout` 会启动真实 Electron 页面并测量 Claude Desktop
三个按钮的位置。修复前垂直中心差为 75 像素，修复后为 0。

## 尚需用户验收

安装新更新包后，在正常窗口与较窄窗口下查看 Claude Desktop、Claude Code 以及
Web 产品卡片。

## 防复发门禁

任何新增产品操作能力都必须放入统一操作栏，并通过真实 Electron 布局测量，不能
只依赖构建成功或静态 CSS 检查。
