# Mailpit 本地主机端口失效复盘

日期：2026-08-01

## 现象

统一身份验收成功发送注册邮件，但 Windows 主机访问 `127.0.0.1:8025` 时 TCP 可以连接、HTTP 请求却立即得到空响应；同一容器内部访问 Mailpit API 正常，容器健康检查也一直为 healthy。

## 根因

长时间运行的 Docker Desktop 端口转发保留了监听套接字，但该主机绑定已不能把 HTTP 请求转发到仍然健康的 Mailpit 容器。仅检查容器健康无法发现这类主机侧失效。

## 修复

- 本地发布验收在启动整套服务后，按固定 Compose 配置强制重建 Mailpit 支持容器，刷新 `127.0.0.1:8025` 的主机端口绑定。
- 身份验收的邮箱轮询允许单次瞬时连接失败继续重试；持续失败仍会保留最后一个网络错误并让验收失败。
- Mailpit 仍使用固定只读镜像和最小权限配置，不进入后台可调整的执行边界。

## 验证

- 重建前：主机 `curl` 返回 empty reply，容器内部 API 返回 200。
- 重建后：主机 API 返回 200，注册验证码读取与统一身份/社区验收必须重新全程通过。
