# 厂商页因入口行为版本不一致白屏

## 用户可见现象

主页和全部厂商页正常，进入厂商详情后页面变空白。

## 原因

开发服务器仍复用旧的本地 CommonJS 预构建结果，而新的 `ProductRow` 已直接读取 `behavior.entryPoints`。开发期模块版本短暂不一致时，属性为 `undefined` 并触发渲染异常。

## 修复与防复发

- 产品卡先把缺失的入口集合归一为空数组，目录版本短暂不一致时不再拖垮整个厂商页。
- 重启开发服务器刷新本地预构建；正式构建仍把共享策略与界面打进同一制品。
- 产品入口 UI 测试锁定空值保护，Electron 产品布局验收继续覆盖真实厂商详情页。
