# 产品安装包下载前磁盘检查

## 背景

Ollama Windows 安装包约 1.46 GB，ComfyUI Desktop 安装后还需要较大的运行环境空间。原下载器只在文件写入失败时得到系统错误，用户可能下载到中途才发现空间不足。

## 实现

- 客户端取得官方响应头并验证最终跳转域名后、读取正文前，获取下载目标所在卷的实际可用空间。
- 下载空间硬门为“剩余安装包字节 + 512 MB 安全余量”。
- 断点续传只计算尚未下载的字节；服务器忽略 Range 时，已有 `.part` 将被覆盖，因此不会重复计费。
- 官方响应无法提供可信总大小时停止下载，不在未知大小下继续写盘。
- 空间不足返回可用字节、所需字节、差额、剩余下载量、安全余量和下载目录。
- 产品卡提供“更换下载位置”和“重新下载”。
- 同一时间只允许一个产品安装包下载，降低多个大包同时抢占同一磁盘的风险。
- 写入阶段若 Windows 返回 `ENOSPC`，保留可信断点并提示清理空间后继续。

## 安装空间提示

- ComfyUI Desktop：官方 Windows 文档建议对应磁盘至少保留约 15 GB。
- Ollama：官方 Windows 文档说明二进制安装至少需要 4 GB；模型还可能需要数十到数百 GB，因此模型空间只提示，不设置虚假的固定硬门。
- 安装建议与“下载目录是否能写完整安装包”分开呈现，因为用户可能在安装器中选择另一个磁盘。

## 验证

- Windows `fs.statfsSync(..., { bigint: true })` 在当前下载卷成功返回可用空间。
- 真实 Comfy 下载界面显示下载所需、当前可用和安装建议预留 15 GB。
- 下载完成后的 SHA-256 与 Authenticode 签名校验继续通过。
- 单元测试覆盖空间足够、精确差额、未知大小拒绝、断点剩余字节计算，以及不一致 `Content-Range` 拒绝。
