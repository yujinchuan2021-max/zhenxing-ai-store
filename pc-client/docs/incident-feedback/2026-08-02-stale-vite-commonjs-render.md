# 开发页面复用旧依赖导致白屏

## 用户可见现象

本地开发页面可能只显示窗口标题，正文完全空白；控制台提示目录搜索函数不可调用。新开的 Electron 页面正常，说明目录数据和正式代码并未损坏。

## 原因

浏览器页面复用了上一次 Vite 进程生成的 CommonJS 预编译依赖。共享目录模块更新后，旧页面仍持有旧导出形状，导致 React 首次渲染中断。

## 修复与防复发

- 开发服务启动时强制重建 Vite 预编译依赖。
- 增加 `npm run test:dev-render`，使用隐藏的 Electron 页面验证根界面确实渲染出可见内容，而不只验证 HTTP 200。
- 正式构建继续把共享模块与界面打进同一制品，不依赖开发期缓存。
