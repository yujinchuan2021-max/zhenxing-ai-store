# 厂商 Logo 长期显示字母占位

- 日期：2026-08-02
- 影响：全部厂商页、AI 可接入厂商页、搜索结果和生态资源主目录
- 用户表现：厂商卡片长期只显示字母色块；后台虽有图片 URL 字段，但无法保证图片可用、可追溯或随目录更新。

## 原因

目录只保存了任意 HTTPS `iconUrl`，没有上传、格式校验、内容哈希、来源清单和发布源资产路由。远程热链还可能失效、被替换或继续命中旧缓存；图片加载失败时客户端也没有可靠回退。

## 修复

- 后台上传 PNG、JPG、WebP、ICO 或经过静态安全检查的自包含 SVG。
- 图片保存为 `vendor-icons/<sha256>.<ext>`，目录只下发路径、SHA-256 与 MIME。
- 后台保存官方来源 URL，保存草稿和发布前重新验证文件、类型和哈希。
- 草稿只保存受管 `iconAsset`；发布时可为旧客户端物化为受控发布主机下的内容寻址 `iconUrl`。客户端只接受已签名相对资产或受控 `vendor-icons/<sha256>.<ext>` 地址，拒绝任意图片热链。
- 加载失败时立即回退到厂商文字标记。
- 当前 158 个厂商中 129 个已有可追溯资产；其余 29 个厂商使用已审核文字回退，直到取得可核验且适合本目录使用的官方素材。具体名单由 `admin/data/vendor-icon-fallbacks.json` 固定并参与发布前校验，任何厂商都不能处于“既无资产、也无审核兜底”的未定义状态。

## 验证

- 覆盖路径穿越、错误哈希、篡改文件、伪造格式、危险 SVG、远程 URL 和坏图回退。
- 后台支持上传、预览和移除；本地发布源按哈希文件提供 immutable 缓存。
- Logo 更新只需后台上传并发布新目录，不需要重新封装 PC 客户端。
