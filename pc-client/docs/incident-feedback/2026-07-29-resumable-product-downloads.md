# 产品安装包取消、重试与断点续传

## 问题

Ollama Windows 安装包超过 1 GB。原下载器取消或网络异常时会删除 `.part` 文件，用户只能从零开始重新下载。

## 实现

- 产品下载可以在界面中点击“暂停”。
- 暂停或网络失败后保留固定目标路径对应的 `.part` 文件和受控元数据。
- 客户端重启后会识别仍然可信的断点，并显示“继续下载”。
- 继续时发送标准 `Range: bytes=<已下载字节>-`。
- 只有服务器返回 `206`，且 `Content-Range` 起点与本地文件大小完全一致时才追加。
- 如果服务器忽略 Range 并返回 `200`，客户端会安全覆盖并从头下载。
- 如果服务器返回的断点起点不一致，客户端拒绝拼接文件。
- 未完成记录仍受固定产品 ID、官方入口、文件名和下载目录边界约束。
- 下载完成后重新计算整个文件的 SHA-256，并继续执行 Authenticode 与签发者校验。

## 验证

2026-07-29 使用 Comfy Desktop 官方安装包完成真实链路：

1. 启动下载。
2. 在 4,098 字节时暂停。
3. `.part` 文件与总大小 158,888,904 字节的记录均保留。
4. 点击继续下载，完成记录显示 `resumedFrom: 4098`。
5. 最终 SHA-256 为 `41373C8430E9B3B8E8E1FDD66FEB7FC4299A03A6AC1BF9CDB654391AD932E443`。
6. Authenticode 状态为 `Valid`，签发者为 `Drip Artificial Inc`。
