# Web 与 Windows 重复产品及后台入口失配

日期：2026-08-02

## 用户可见问题

同一产品的网页版和 Windows 客户端被拆成两张产品卡，增加选择成本；后台只能编辑固定官网和教程字段，无法按产品实际情况增删按钮。CLI 还可能因组件关系被隐藏在桌面产品下面。

## 根因

目录把“产品身份”和“访问入口”建模为同一个层级，客户端再按每条产品记录渲染一张卡。组件目录也没有禁止把 CLI 当作子产品。

## 修复与防回归

- 新增严格校验的有序 `entryPoints`，链接入口仅允许 HTTPS，本地入口不能携带命令、参数、路径或下载配置。
- 客户端通用渲染入口；安装生命周期继续绑定产品现有本地白名单。
- 合并六组 Web/Windows 重复记录并保留托管桌面产品 ID。
- CLI 显示为独立一级产品，组件校验拒绝 CLI 子项。
- 后台提供入口的新增、删除、排序、类型、文案和链接编辑。
- 自动发现把入口 URL 纳入去重，且只能生成停用的安全链接入口。

## 验收门禁

目录校验、后台发布校验、入口安全测试、组件关系测试、客户端 TypeScript 构建和实际页面回归必须同时通过；仅通过单元测试不视为用户设备验收。
